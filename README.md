## 差价出在回程线路，不在 CPU

香港的带宽资源比美国贵得多，这是一层成本。更贵的一层是回大陆的路由：走国际 BGP 绕行，和走三网直连，采购价不是一个量级。

野草云把线路分成三档，可以当作理解整个市场的样本：

- **优质 BGP**：电信回程 CMI、联通回程 CU/NTT/CMI 均衡、移动回程 Level3，带宽档位 200～500Mbps，适合大多数国内业务。
- **精品 BGP**：电信联通都走 CU、移动走 CMI，国内访问优化更好，但带宽只有 3～15Mbps。
- **国际 BGP**：不含 CMI 和 CU，国内延迟高，面向东南亚和海外访客。

DigitalVirt 的分档逻辑一样，价格标得更直白：纯国际线路 ¥21/月，三网直连 ¥79/月，电信 CN2 加联通 10099 加移动 CMI 的精品网 ¥109/月。同一家、同样 1 核 1G，三档差价五倍。

所以判断一个香港 VPS 贵不贵，第一个问题不是“配置够不够”，而是“访问它的人在哪”。访客在深圳、上海、成都，走国际 BGP 的机器晚高峰会明显卡；访客本来就在新加坡、雅加达，多花的线路钱一分都用不上。

至于延迟数字，商家页面上的宣传口径差异很大。天下数据宣称精品线路访问大陆 10～30ms、标准 BGP 15～50ms，这些是官方宣传值，没有第三方实测支撑，只能作为量级参考，不能当承诺。

香港 VPS 的首年折扣做得很凶，续费价才是你第二年真正要付的钱。

另一条路是买“续费同价”的特惠款。野草云的特惠款不用优惠码，续费也同价，代价是配置缩水：流量制而不是不限量，200Mbps 带宽配 500～800GB 月流量，超出后限速到 1Mbps；而且官方写明“购买起 2 年内续费同价，之后随成本调整”。也就是说，同价承诺有期限。

## 下单前必须核对的四件事

**一、流量和带宽是两件事**

“不限流量”和“不限带宽”经常被混着说。野草云的标准款标 200Mbps 不限流量，特惠款标 200Mbps 加 500～800GB 月流量，超出后限速 1Mbps。1Mbps 是什么概念？打开一个普通网页都要等。

Akile 的部分方案在公开记录里标注了超出流量后限速 10Mbps，并提供付费重置流量。10Mbps 比 1Mbps 实用得多，但仍然不是原来的端口速度。

下单前问清楚三件事：超流量是限速还是停机、限到多少、重置流量多少钱。

**二、IP 是不是原生香港**

野草云官网写明，因为 IPv4 紧缺，分配到的可能是 APNIC、RIPE、AFRINIC 区域的 IP，只是宣告到香港；下单后 24 小时内可以免费换一次。DigitalVirt 的香港机房用的是广播 IP，查询归属地时可能显示其他地区。

对普通建站没影响，对流媒体解锁、支付风控、区域限定的服务有影响。这类业务下单前先问 IP 段和归属地。

**三、Windows 要不要额外加钱**

野草云的特惠款和标准款默认只支持 Linux，需要 Windows 得另选支持方案或加配。香港 VPS 的 Windows 授权通常单独计价，价格表上不写，结账时才出现。

**四、退款窗口和条件**

野草云自购买起 3 天内支持退款，前提是没有滥用或违反条款。DigitalVirt 的正价商品总流量不超过 10GB 可全额退款，但用了优惠码、流量超 10G、IP 被墙都不退；换 IP 50 元/次，过户 10 元/次。

还有一种按天阶梯退的设计：3 天内退八成、3 到 7 天退五成、7 到 10 天退两成，超过 10 天不退，退款只进账户余额而不是原路返回。这种规则对“先买年付试试”的人很不友好。

所以第一次买香港 VPS，先月付跑一周，确认线路和稳定性，再决定要不要转年付。
